## 📖 Descripción del Proyecto

**Autos NARLA** es un sistema de gestión para un auto lote, desarrollado en **C# (Windows Forms)** bajo el patrón **MVC (Model-View-Controller)** y utilizando **SQL Server 2022** como base de datos.

El sistema permite gestionar de forma eficiente la información de vehículos, clientes y ventas, integrando funcionalidades de consultas, transacciones y procedimientos almacenados.
