# Proyecto Final - Autos NARLA (C# MVC)

Este proyecto corresponde al desarrollo de una aplicación de escritorio en **C# con SQL Server**, implementando el patrón **Modelo - Vista - Controlador (MVC)**.

##  Funcionalidades Principales
1. Gestión de Clientes: registro, consulta y actualización.
2. Gestión de Vehículos: inventario, registro y filtros.
3. Gestión de Ventas: registro y descuentos.
4. Menú Principal: acceso a todos los módulos del sistema.

##  Estructura del Proyecto
1. Models:** Clases que representan las entidades (Cliente, Vehículo, Venta).
2. Controllers:** Lógica de conexión y operaciones con la base de datos.
3. Views:** Formularios Windows Forms que conforman la interfaz gráfica.
4. Database:** Conectada a SQL Server 2022.
